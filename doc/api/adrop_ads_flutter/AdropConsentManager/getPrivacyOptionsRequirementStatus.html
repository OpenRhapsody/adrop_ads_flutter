Future<AdropPrivacyOptionsRequirementStatus> getPrivacyOptionsRequirementStatus()

Whether a privacy options (privacy settings) entry point must be shown

Meaningful after requestConsentInfoUpdate completes in this app session; before that it is AdropPrivacyOptionsRequirementStatus.unknown or the previous session's value. When it is AdropPrivacyOptionsRequirementStatus.required, show the entry point (e.g. in your settings screen) and call showPrivacyOptionsForm from it.

Implementation

Future<AdropPrivacyOptionsRequirementStatus>
    getPrivacyOptionsRequirementStatus() async {
  try {
    final result = await _methodChannel
        .invokeMethod<int>(AdropMethod.getPrivacyOptionsRequirementStatus);
    return AdropPrivacyOptionsRequirementStatus.fromValue(result ?? 0);
  } catch (e) {
    log('Error getting privacy options requirement status: $e',
        name: 'AdropConsentManager');
    return AdropPrivacyOptionsRequirementStatus.unknown;
  }
}
